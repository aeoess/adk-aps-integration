# adk-aps-integration

APS integration for Google's [Agent Development Kit](https://github.com/google/adk-python).

**The working skeleton lives on the [`integration-skeleton`](https://github.com/aeoess/adk-aps-integration/tree/integration-skeleton) branch.**

This `main` branch is kept empty on purpose so co-maintainers can PR into
`integration-skeleton` without stepping on each other. Once the skeleton
settles, it will be merged here.

Committed on [google/adk-python#5164](https://github.com/google/adk-python/issues/5164).
